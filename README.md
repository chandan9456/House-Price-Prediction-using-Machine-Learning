## House-Price-Prediction-using-Machine-Learning
House Price Prediction using Machine Learning project
# Objective:
The main objective of this project is to predict the price of a house based on different features, such as area, number of bedrooms, bathrooms, location-related information, parking, etc.
This is a Supervised Machine Learning – Regression problem because:
We have historical house data. 
The target/output is a house price, which is a continuous numerical value. 
We train the model using existing data and predict prices for new houses. 

# Business Problem / Problem Statement

The real-world problem is:
House prices depend on many factors, and manually estimating the correct price can be difficult.
So, we build a machine learning model that learns from historical house data and predicts the expected price of a house based on its characteristics.
